# Checklist для тестирования бота Mimoru

## Автоматические проверки

### Ежедневные
```bash
# Быстрый гейт - компиляция, lint, unit-тесты
./scripts/check.sh

# Полная проверка с PostgreSQL
./scripts/check_db.sh  # требует DATABASE_URL, REDIS_URL, BOT_TOKEN
```

### CI/CD Pipeline
Проверки проходят автоматически при каждом push:
- `test` - unit-тесты без БД
- `test-db` - тесты с реальной базой

## Ручное тестирование на сервере

### Тест 1: Бан через команду в группе
**Сценарий:**
1. Ответьте на сообщение пользователя командой `/бан` или `бан`
2. Выберите причину из кнопок

**Ожидаемый результат:**
- [ ] Бан выполняется мгновенно (без диалогов подтверждения)
- [ ] Сообщение бота исчезает через 25 секунд
- [ ] Сообщения нарушителя удаляются

### Тест 2: Бан из панели управления
**Сценарий:**
1. Откройте личное меню бота → "Мои группы" → нужная группа → "Участники"
2. Выберите участника → "Наказать" → "Блокировка"
3. Выберите причину

**Ожидаемый результат:**
- [ ] Появляется диалог с 3 кнопками: Бан / Бан+Очистка / Отмена
- [ ] После выбора "Бан" - наказание выполняется
- [ ] Сообщение админа в группе исчезает через 25 секунд
- [ ] Кнопка "Отмена" работает (ничего не делает)

### Тест 3: Жалоба
**Сценарий:**
1. Ответьте на сообщение пользователя командой `жалоба`, `доложить` или `нарушитель`

**Ожидаемый результат:**
- [ ] Жалоба сохранена
- [ ] Уведомления админам отправлены
- [ ] Если часть админов не получила - видно "X из Y получили"
- [ ] Сообщение жалобы исчезает через 45 секунд

### Тест 4: Мут
**Сценарий:**
1. `/мут` или `мут` → выбор причины → выбор срока

**Ожидаемый результат:**
- [ ] Мут выполняется сразу после выбора причины
- [ ] Сообщение бота исчезает через 25 секунд

### Тест 5: Предупреждение
**Сценарий:**
1. Ответьте на сообщение командой `пред`

**Ожидаемый результат:**
- [ ] Предупреждение выдано мгновенно
- [ ] Сообщение бота исчезает через 25 секунд

## Проверка логов сервера

```bash
# После деплоя
docker compose logs --tail=200 bot

# Искать ошибки
docker compose logs bot | grep -iE "(error|exception|traceback|fail|critical)"

# Проверка удаления сообщений
docker compose logs bot | grep -i "schedule\|ttl\|deletion"
```

### Ожидаемые сообщения в логах:
- [ ] `bot_started` - успешный старт
- [ ] `preflight passed` - все сервисы доступны
- [ ] `TelegramPolling` - работает
- [ ] Нет `ERROR`, `Exception`, `Traceback` в последних 100 строках
